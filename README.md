# 더 커뮤니티 2: 보이지 않는 손 - 자율 에이전트 몬테카를로 시뮬레이터

복잡한 비대칭 정보와 경제·사회적 상호작용이 결합된 시뮬레이션 게임 **'더 커뮤니티 2 (The Community 2: Invisible Hand)'**의 동학을 분석하기 위한 자율 에이전트 기반의 고성능 몬테카를로 시뮬레이터입니다.

---

## 1. 프로젝트 개요 및 핵심 철학

1. **비대칭 정보 (Asymmetric Information)**:
   - 각 팀은 전체 시스템 정보의 일부만을 소유합니다.
   - **블루 팀**만이 글로벌 라이프 비축량의 한도(50개)를 인지하며 독점 생산 권한을 가집니다.
   - **화이트 팀**은 디지털 화폐(보석)의 무제한 발행권을 가지지만, 화폐 가치 희석의 딜레마를 마주합니다.
   - **레드 팀**은 막강한 크레딧 생산력과 군사력(폭탄 제조권)을 보유하며, 공해 재앙을 지렛대 삼아 시스템 협박을 가합니다.
   - **블랙 에이전트**는 라이프가 불필요한 은밀한 군수업자이자 마트 운영자로, 분쟁을 조장하여 자산을 축적합니다 (환수 조각 3개 수집 시 자산 몰수).

2. **멜서스 트랩 (Malthusian Trap)**:
   - 게임 기간: **9일**
   - 총 인원: **12인의 필멸자 (화이트 6인, 블루 3인, 레드 3인)** + 블랙 1인
   - 생존을 위한 총 필요 라이프: `12인 × 9일 = 108개`
   - 초기 보급 라이프: `14 (화이트) + 19 (블루) + 9 (레드) = 42개`
   - 전역 추가 생산 가능 라이프 한도: `50개`
   - **이론상 최대 공급 가능 라이프**: `42 + 50 = 92개`
   - ➡️ **16개 이상의 필연적인 라이프 부족이 발생**하여, 어떠한 완벽한 협동이 있어도 전원 생존이 불가능한 수학적 멜서스 트랩이 형성됩니다.

3. **게임 이론 (Game Theory)**:
   - 협력과 배신, 독점적 라이프 가격 책정, 군사적 선제 타격, 공해 임계점 치킨 게임.

## 3. 일일 3단계 턴 루프 (Daily Turn Loop)

- **Phase 1: 오전 생산 (Morning Production)**
  - 화이트: 생존 위기 수준에 맞춰 보석(디지털 화폐) 신규 발행량 결정.
  - 블루: 보유 크레딧과 테크 효율을 기반으로 전역 라이프 비축량(50개 한도) 내에서 라이프 생산.
  - 레드: 무공해 생산(기본 크레딧) vs 공해 생산(2배 크레딧, 공해 지수 +8) 선택. 공해 수치 50 초과 시 **재앙 발발 (전체 재화 30% 즉시 소멸)**.
  - 블랙: 마트 물가 지수 조정 및 첩보 수집.

- **Phase 2: 오후 거래 / 기술 / 전쟁 (Afternoon Phase)**
  - **시장 거래**: 화이트의 보석-라이프 매수 오퍼, 블루의 고가 라이프 매도 오퍼, 레드의 크레딧 거래 체결.
  - **기술 투자**: 크레딧을 소비하여 생산 효율 및 단가 개선 (Level 1~3).
  - **군사 무기 거래 & 교전**: 블랙 마트에서 보석으로 전쟁 선포권(15개) 및 무기(A급 30개, B급 20개, C급 10개)를 구매하여 타 진영 타격. 구매 대금(보석)은 블랙으로 흡수.

- **Phase 3: 저녁 라이프 제출 및 생존 판정 (Evening Survival)**
  - 화이트, 블루, 레드 생존 인원은 각 1개의 라이프를 시스템에 제출.
  - 보유 라이프 부족 시 해당 인원 탈락 (자연 도태).
  - 블랙 마트: 1일차 라이프 소모 면제(0개), 2일차부터 매일 1개 라이프 운영비 소모.
  - 보석 유통량 대비 단위 가치 재계산: `단위 가치 = 2억 원 / 총 보석 유통량`.

## 4. 실행 방법

### 웹 인터랙티브 대시보드 실행 (브라우저 자동 열림)
```bash
python web_server.py
```
> 브라우저에서 `http://localhost:8000`으로 접속하면 실시간 대화형 시뮬레이터와 인터랙티브 Chart.js 그래프를 조작할 수 있습니다.

### 단일 세션 상세 시뮬레이션 (CLI 로그 관찰)
```bash
python main.py --mode single
```

### 대규모 몬테카를로 시뮬레이션 (통계 산출 및 시각화 차트 생성)
```bash
python main.py --mode monte_carlo --runs 1000 --output-dir output
```

### 테스트 스위트 실행 (11개 테스트 통과)
```bash
python -m pytest -v
```

## 5. 몬테카를로 시뮬레이션 결과 예시 (1,000회 실행 기준)

| 지표 | 화이트 (6인) | 블루 (3인) | 레드 (3인) | 블랙 (1인) |
|:---:|:---:|:---:|:---:|:---:|
| **최종 생존율** | 3.6% | **87.3%** | 30.1% | 100.0% |
| **1인당 평균 기대 상금** | ~2,410,000 원 | **~34,250,000 원** | ~1,730,000 원 | ~2,700,000 원 |

- **전쟁 발발률**: `81.6%` (레드의 선제 타격 빈도 높음)
- **공해 재앙 발생률**: `95.3%` (레드의 고효율 공해 생산 유혹으로 임계점 돌파)
- **블랙 자산 몰수율**: `6.3%` (3조각 완성 성공 확률)
